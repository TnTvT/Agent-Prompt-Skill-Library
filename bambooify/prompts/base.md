# Base image-edit template

Read after inspecting the source and selecting component treatments. Replace all `{{...}}` variables with concrete image-specific instructions; do not send the template verbatim. The component plan should be short, spatially unambiguous prose. Resolve the two preservation policies according to the request and defaults.

```text
Edit the attached source image. Transform only {{target_subject_and_location}} into a believable object constructed from woven bamboo strips.

IDENTITY AND GEOMETRY
Preserve {{silhouette_proportions_pose_camera_and_key_features}}. Keep the original locations, sizes, outlines, and expressions of identifying details. Preserve the composition and do not add accessories or duplicate components.

CONSTRUCTION
Use {{resolved_weave_style_and_density}}. Build the surface from visibly interlaced strips with consistent local over-under crossings, subtle strip thickness, and small contact shadows. Let strips follow each part's curvature. Connect adjacent regions with plausible bindings, wrapped edges, or seams. Keep relief restrained so the source silhouette remains recognizable. Render bamboo as the construction material, not a printed pattern on an unchanged smooth object.

COMPONENT PLAN
{{component_by_component_weave_direction_scale_color_and_edge_treatment}}

COLOR
{{resolved_color_policy_with_actual_regional_colors_or_natural_tone_mapping}}

PROTECTED REGIONS AND PRESENTATION
{{resolved_background_support_lighting_and_transparency_policy}}
{{additional_user_constraints}}

Avoid disconnected fibers, unexplained strip endings, smooth plastic patches on transformed areas, excessive holes, displaced facial features, and accidental changes to protected regions. Render a coherent physical object with lighting consistent with the scene.
```

For default color preservation, name the actual color blocks and translate them into dyed/stained bamboo; do not apply a global tan wash. For default scene preservation, identify the visible stand, tabletop, background, crop, and lighting that must remain. If no additional constraints apply, replace that variable with a concrete brief instruction such as “Do not introduce any other changes.”
