# Bambooify — 竹编风格图像转换 Skill

Bambooify 将输入图片中的指定主体转换成可信的竹编物件。它先理解结构和部件，再为当前图片生成专用编辑提示词，让竹篾沿形体编织、交错和收边。

## 核心原则

- 保持主体轮廓、比例、姿态、视角和辨识特征。
- 表现真实的上下穿插、曲面走向与包边，而非覆盖一层竹纹。
- 按部件选择编法：主体、五官、外圈、头发与挂环分别处理。
- 默认保留各区域原色，以染色竹篾表现；默认保留背景和支架。
- 可选打印友好模式，减少细丝、孤立元素和微小孔洞，便于后续建模参考。

## 使用

将整个 `bambooify` 文件夹放入支持 `SKILL.md` 的宿主的技能目录，保留相对路径。仅存入 GitHub 不会自动安装到聊天环境。也可让支持读取文件的 agent 直接读取 [SKILL.md](SKILL.md)，并提供原图。

示例请求：

> 使用 Bambooify，把这张图里的圆形表情挂件变成竹编，保留黄色、眼型和嘴形，支架与背景不变。

> 使用 Bambooify，把这个人物摆件转成竹编，开启 print_friendly，保留原来的发型、姿势和配色。

参数可用自然语言说明，也可以附上：

```yaml
weave_density: medium    # coarse | medium | fine
weave_style: auto        # auto | plain | twill | hexagonal | random
preserve_color: true
preserve_background: true
print_friendly: false
```

`auto` 根据部件选择编法。指定编法主要控制主体表面，边缘、挂环和细节仍采用适合的构造。密度描述的是图像中的相对尺度，不是毫米尺寸。开启打印友好模式后，过细编织会适度简化；若与用户明确要求冲突，先说明取舍。

## 工具与边界

需要能够查看原图并以原图为输入的图像编辑工具；此 Skill 不绑定厂商、模型或 API，也不包含密钥。工具不可用时返回完成的编辑提示词，不声称已生成图片。用户只需要提示词时不会调用编辑工具。

打印友好模式输出的是设计参考图，不能直接导出 STL/3MF，也不能确认壁厚、流形、强度或支撑需求。实际可打印性仍需结合成品尺寸、材料、打印设备、三维建模和切片检查判断。默认背景保持是编辑目标，不是像素级保证。

## 第一版验收场景

| 输入场景 | 预期行为 |
| --- | --- |
| 黄色圆牌、眼睛、嘴、外圈、挂环和支架 | 面部经纬编；细节密编；深色染竹保留瞳孔和嘴；环形包边；支架不变 |
| 有头发与耳朵的人物摆件 | 曲面编织贴合头部；发束保持原走向；耳朵有包边；五官位置不变 |
| 同一物体开启打印友好模式 | 减少毛丝、孤立竹条和微孔；保持主体比例和关键特征 |
| 未提供图片或目标不明确 | 请求缺失图片或澄清目标，不编造输入 |
| 无图像编辑工具或只请求提示词 | 返回具体、无未填变量的提示词，并说明未生成图片 |

这些是待实图验证的验收场景，不是已经通过的图像回归测试。该仓库未附带此前讨论的原图或生成结果。
