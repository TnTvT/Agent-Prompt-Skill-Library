# HueForge Clean Flat-Color Cel-Shading

Edit the image the user provides. Follow the English prompt below verbatim. Do not reword it.

## English prompt

Edit the provided image using a Clean Flat-Color Cel-Shading approach, optimized for HueForge and multi-color 3D printing.

Preserve:

- Original character identity, facial expression, hairstyle, pose, proportions, and composition.
- Original background color and overall visual style.
- Important outlines, recognizable details, and essential shading.

Improve:

- Remove all visible noise, grain, speckles, color contamination, and unwanted artifacts.
- Replace complex gradients and muddy color transitions with clean, uniform color regions.
- Consolidate nearly identical colors into consistent flat fills.
- Simplify grayscale shading into distinct, hard-edged tonal regions.
- Keep black, white, and gray regions visually separated.
- Make the background perfectly uniform, with no texture, gradients, or color variations.
- Preserve crisp, smooth outlines and sharp boundaries between colors.

Strict requirements:

- No added texture, dithering, grain, or artificial noise.
- No unnecessary gradients or tiny isolated color patches.
- No added decorative details.
- No changes to character identity or composition.
- No blur or loss of important facial details.
- No unwanted color shifts.
- Maintain a clean, professional anime cel-shaded illustration style.

Target result:
An ultra-clean, high-contrast, flat-color illustration with smooth solid fills, simplified grayscale shading, crisp edges, and minimal unnecessary color variation, suitable for color-limited 3D printing.
