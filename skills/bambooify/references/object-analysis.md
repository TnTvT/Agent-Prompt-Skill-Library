# Object analysis

Inspect the source before drafting an edit. Separate the selected subject from its surroundings and preserve the facts that make it recognizable. A support touching the subject is not automatically part of the transformation.

## Compact planning record

For each significant region, record:

| Field | What to capture |
| --- | --- |
| Region | Unambiguous name and location |
| Geometry | Flat, curved, hollow, narrow, projecting; observed outline and orientation |
| Identity anchors | Feature position, expression, proportions, markings, or functional opening |
| Treatment | Weave family, direction, relative density, edge/attachment strategy |
| Color | Original regional color or chosen natural-tone contrast |
| Protection | What must not move, disappear, or be transformed |

Do not turn this into an exhaustive segmentation task. Use only distinctions that change the edit. If a part is occluded, preserve the visible evidence without claiming to know its hidden construction.

## Example: round expressive plaque

Apply this mapping only when the input actually contains these parts:

| Part | Strategy | Preserve |
| --- | --- | --- |
| Main face | Plain weave on the shallow face surface | Circular silhouette and original face color |
| Outer rim | Wrapped bamboo ring | Existing outline and rim width |
| Eye regions | Finer local weave within each eye boundary | Exact eye shape, spacing, and expression |
| Pupils and mouth | Dark stained strips or bound bamboo details | Position, shape, and color contrast |
| Hanging loop | Bent/bound bamboo following the original loop | Opening and attachment position |
| Stand and background | Protected surroundings | Material, geometry, position, and composition |

## Example: figurine with hair and ears

Let strips curve around the head without shifting facial features. Map hair locks to directional bundles following the source hairstyle, keeping the original volume. Treat ears as small curved regions with a bound perimeter, not new basket handles. Use larger weave on the torso and finer treatment on identity-critical details. Keep the pose, accessories, camera angle, and regional colors unless the request changes them.

## Output comparison

Compare the source and result at whole-object and detail scales. Check that:

- The same subject remains recognizable at a glance, with matching silhouette and pose.
- Eyes, mouth, hairline, openings, and other anchors retain their placement and shape.
- Regional colors remain distinguishable under the selected color policy.
- Weave follows form and has plausible crossings, terminations, and joins.
- Protected supports, background, framing, and transparency are retained.
- Print-friendly simplification, when requested, reduces fragile-looking detail without erasing identity.

If a check fails, target the observed defect in the next edit. If the result cannot be inspected, report it as unverified rather than asserting that it passed.
